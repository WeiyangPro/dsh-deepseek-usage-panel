# dsh-deepseek-usage-panel v0.2.2 更新说明

- **兼容 dsh-better-sidebar 插件（含 v0.18.0）**：UI 改用 `react-dom` portal 挂载到 body 级 host（`z-index:30`，高于更侧栏 host 的 25），并实时读取其写入 `<html>` 的 `--dsh-sidebar-width` 保留宽度——右侧工作台打开瞬间悬浮球/面板自动让到其左侧、关闭后还原，之后拖拽自由、可悬浮在工作台上方，互不遮挡。

- **新增 悬浮球贴边响应式自适应设计**：悬浮球可真正贴住屏幕左/右/上/下边缘停靠（按自身尺寸夹取）；贴边后展开的胶囊自动朝屏幕内侧生长方向自适应翻转，既不溢出屏幕、也无二次切换跳变。

- **优化 部分前端UI样式/特性**：面板定位参照改为整个屏幕（视口），出现位置锚定悬浮球右上角；用量/设置面板按各自实际高度夹取，均可拖到页面底部且紧贴悬浮球；悬停/展开/设置等交互更顺滑。

> 数据口径提示：今日 / 近 24 小时 / 会话为本地观测窗口数据，可能与平台全天存在差异，绝对总量以 platform.deepseek.com/usage 为准。

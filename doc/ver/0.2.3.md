# dsh-deepseek-usage-panel v0.2.3 更新说明

- **修复 DSH 新版全局 corner-shape 把圆形变鹅卵石**：新版主题对全部元素下发 `corner-shape: superellipse(1.5)`（见 `dsh-client-ui-theme` 的 corner-shape.css），插件在自身子树内（含伪元素）强制 `corner-shape: round`，悬浮球、胶囊、面板内所有圆形/药丸恢复正圆。

- **新增 余额观测账本与余额校正（数据口径透明）**：官方余额接口无消费流水，按「余额下降=消费、上升=待核对（充值/赠金）」以定点金额（1e-8 单位）记账；「今日已观测消费」带来源标签（已观测 / 已校正 / 待核对）；面板内可填入实际到账金额与非调用扣减校正，带 revision 乐观并发（数据变更返回 409）；账本独立存 `ledger.json`，不污染 token 统计。

- **新增 官方浏览器信任栅栏**：全部 `/dsh-usage/api/*` 接口优先走 DSH 官方 `connection.requestRejection`（会话级信任栅栏），服务缺失或异常时回退到原有 Host 白名单栅栏，两层都通过才放行。

- **优化 余额接口健壮性**：多币种选择改为「CNY 且余额>0 → 任意非零项 → CNY → USD → 第一项」，不再因数组顺序或 CNY 为 0 显示错币种/零余额；瞬时失败（网络/超时/限流/5xx）沿用最近一次成功余额并标记 `stale`（弱提示、不闪错），认证与解析失败不回退；定时轮询与手动刷新共用同一 in-flight 请求。

- **优化 交互与视觉**：余额大数字滚动动画（700ms ease-out 三次方）；「今日」瓷贴标注观测起点（自 HH:MM 起统计，悬停提示可能小于平台全天）；回合用量气泡随胶囊贴边**方向自适应**——胶囊贴左边缘时气泡改为从左缘向右弹出，不再溢出屏幕。

> 数据口径提示：今日 / 近 24 小时 / 会话为本地观测窗口数据，可能与平台全天存在差异，绝对总量以 platform.deepseek.com/usage 为准。

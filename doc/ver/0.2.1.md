# dsh-deepseek-usage-panel v0.2.1 更新说明

- **兼容 dsh-better-sidebar**：面板位置按对话区容器计算，并监听容器尺寸变化自动重夹；与右侧工作台并存时不被遮挡，也不会跑到工作台下方。
- **新增设置面板**（右键悬浮球打开）：余额提醒阈值、悬浮球模式、回合提示、玻璃背景色、玻璃质感、恢复默认设置。
- **新增自定义余额提醒 + 系统通知**：可设阈值（默认 5），触发时胶囊/悬浮球红灯 + 浏览器系统通知一次；未开启提醒时余额 ≤ 2 悬浮球红灯兜底。
- **新增每日模型用量数据图表独立查看**：点击「按模型·今日」的模型名，展开该模型近 24 小时平滑曲线（单时段也显示平滑尖峰）。
- **新增极简悬浮球模式**：平时仅显示悬浮球，悬停时由球“膨胀展开”为胶囊；报警红点贴合球体边角。
- **新增自定义主题设置**：毛玻璃背景色（自动 / 石墨 / 极夜 / 暖阳）与玻璃质感三档（更通透 / 默认值 / 可读性）。

> 数据口径提示：今日 / 近 24 小时 / 会话为本地观测窗口数据，可能与平台全天存在差异，绝对总量以 platform.deepseek.com/usage 为准。
